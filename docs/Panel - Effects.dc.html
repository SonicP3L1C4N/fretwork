Effects panel

Per-track LV2 chain in signal order, first plugin nearest the instrument. Binds chainHere (module list), setEffectControl (knobs/selects, ranges from the plugin's own manifest) and applyVoicing (the cassette: one tape turns several knobs at once; Gx::Fitting.declined names what a voicing left behind). The rig is kept in a file beside the score, not inside it: it names plugins by URI and samples by path, which are facts about one machine.

Voicing "Bass — Come Together" carried the amplifier. Left behind: shaper, jconv convolver, stereoverb — no LV2 plugin ships them, so the label says so.

Build notes: the panel fills the width it is given up to 1180px, and the chain row scrolls sideways rather than shrinking — a knob is 46px whatever the window is, so the cards must not squash and a chain can be longer than the panel is wide. Module cards on #2a2827 with #45413f border; knobs 46px radial-gradient dials, pointer rotation −40°…+40° maps min→max; magenta stripe on the tape label marks the loaded voicing; the footer line reports what a voicing applied and declined.
